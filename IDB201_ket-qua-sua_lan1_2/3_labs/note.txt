IDB201 - database scripts for the labs (givenDB)

DBMS: Microsoft SQL Server 2022 (Developer or Express edition), SQL Server Management Studio (SSMS).
Database name used by every script and lab handout: University

Run order
1. university_sqlserver.sql  - creates the database University (the university schema of DSC, 7th ed.,
                               with the course sample data). Run it before Labs 1-5 and whenever you
                               need a fresh copy; it drops and recreates the database.
2. lab3_scale.sql            - Lab 3, Level 3 (Investigate): creates stu_x and takes_x with @n students
                               (set @n at the top of the script: 1,000 / 10,000 / 100,000).
3. lab5_large.sql            - Lab 5: creates student_big (200,000 rows), takes_big (about 2,000,000 rows)
                               and account (10 rows) in University. Runs for about one minute.

Lab 4 uses no script: students create the database Clinic themselves.
The sample solutions (lecturer copy) are in solutions/labN_solution.sql.
